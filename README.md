# prjcap

Трекер задач для agent-режима — Chromium-расширение для управления проектами, задачами и взаимодействия с AI-агентами через чат.

## Установка

1. Откройте в браузере `chrome://extensions/`
2. Включите «Режим разработчика» (правый верхний угол)
3. Нажмите «Загрузить распакованную» и выберите папку `extension/`

## Возможности

### Popup (кнопка расширения)

- Выбор активного проекта из списка
- **Открыть чат и вставить** — автоматическое открытие страницы agent-чата и вставка текста следующей задачи в поле ввода
- **Копировать промпт** — копирование собранного промпта в буфер обмена
- Создание новых задач прямо из интерфейса
- Редактирование текста задач (для открытых и отправленных)
- Просмотр очереди задач проекта со статусами (open / sent / done)
- Управление проектами: добавление, редактирование, удаление
- **Лента уведомлений** — список задач на сегодня с подсветкой ближайшей
- Кнопка «Расписание» — быстрый переход на страницу таймлайна
- **Импорт / экспорт данных** в JSON (с дедупликацией по ID)
- **Настройки AI-ассистента** — выбор провайдера (OpenRouter / Z-AI), API-ключ, модель

### Расписание (timeline.html)

- Вертикальный таймлайн на весь день с 15-минутными слотами
- Карточки задач привязаны к конкретному времени и дате
- Настраиваемая длительность (15 мин — 3 часа)
- Красная линия текущего времени
- **Drag & Drop** — перетаскивание задач между слотами и днями
- Двойной клик на слот для быстрого создания задачи
- Фильтр по проекту
- Цветовая кодировка проектов (палитра из 16 цветов)
- Навигация по датам (стрелки, кнопка «Сегодня», горячие клавиши)
- Модальное окно для создания и редактирования задач
- Кнопка «Сделано» на карточке задачи
- Кнопки «Открыть чат» и «Копировать промпт» на карточке
- Перетаскиваемая ширина панели «Нераспределённые»
- Управление проектами прямо на странице таймлайна
- **Голосовой ввод задач** (SaluteSpeech / Сбер)

### Периодические задачи

- **Создание шаблонов** повторяющихся задач с выбором дней недели
- Автоматическая генерация экземпляров задач на выбранную дату
- Включение / отключение шаблонов (ON/OFF)
- **Редактирование** существующих шаблонов
- Привязка исходной задачи к шаблону при создании из карточки

### Расширенные свойства проектов

- **Описание** — общее описание проекта
- **Цели** — что планируется достичь
- **Приоритет** — критический / высокий / средний / низкий
- **Критерии завершения** — условия успешного завершения проекта
- Безопасная миграция данных: новые поля опциональны, существующие проекты не затрагиваются

### AI-ассистент

- Плавающая чат-панель в правом нижнем углу (кнопка, горячая клавиша `Ctrl+Shift+A`)
- Подключение к **OpenRouter** (Gemini, DeepSeek, Gemma, Phi, Hermes и др.) и **Z-AI** (GLM-4.7, GLM-5.1)
- Автоматическая сборка контекста: текущие проекты с прогрессом, задачи на сегодня, нераспределённые задачи, выполненное за неделю
- **Просмотр и редактирование контекста** — модальное окно с системным промптом
- Возможность пересборки контекста из актуальных данных
- **Markdown-рендеринг** в сообщениях: жирный, курсив, списки, код, ссылки, цитаты, заголовки
- Панель с изменяемым размером (drag handle)
- Сохранение истории чата между сессиями
- Настройка провайдера, API-ключа и модели через popup

### Обзор прогресса (review.html)

- Три режима просмотра: день / неделя / месяц
- Сводные карточки проектов с процентом выполнения и прогресс-барами
- Статистика: выполнено задач, общее количество, затраченное время, активных проектов
- **Стековый график нагрузки** по дням с разбивкой по проектам
- Список выполненных задач за период
- Фильтрация по проекту
- Навигация по периодам (стрелки, кнопка «Сегодня»)

### Промпт-система

- Каждая задача строит промпт из: **instruction prefix** + текст задачи + **agent tail**
- Автоматическая вставка промпта в поле чата агента
- CSS-селектор поля ввода настраивается для каждого проекта
- Умный поиск поля ввода на странице: textarea → input → contentEditable → role=textbox

### Горячие клавиши (timeline)

| Клавиша | Действие |
|---------|----------|
| `Ctrl+Shift+A` | Открыть / закрыть AI-ассистента |
| `Escape` | Закрыть активную модалку или ассистента |
| `←` / `→` | Перейти на день назад / вперёд |
| `t` | Перейти к сегодняшнему дню |

### Горячие клавиши (review)

| Клавиша | Действие |
|---------|----------|
| `←` / `→` | Предыдущий / следующий период |
| `t` | Перейти к текущему периоду |

## Хранение данных

Все данные хранятся локально в `chrome.storage.local`:
- `projects` — массив проектов
- `tasks` — массив задач
- `recurring` — массив шаблонов периодических задач
- `llm_settings` — настройки LLM (провайдер, ключи, модели)
- `assistant_history` — история чата с AI-ассистентом
- `lastProjectId` — последний выбранный проект
